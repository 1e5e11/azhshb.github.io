啊这函数画板

一个纯浏览器端的函数画板：绘制曲线、构造几何对象、求导积分、计算解析解并化简（支持含变量的表达式）、动画轨迹…… 本版本已将服务端合并进客户端——无需 Node.js、无需联网，双击网页即可使用全部功能。 官网：http://h.ssssssss.eu.org/

进入主项目 → 用户文档 解析解文档 独立化简器

📈 函数绘图

解析式建曲线、极坐标、取值范围、精度与缩放控制、自动合理化、黑白模式。

📐 几何构造

交点、线段、圆、垂线、平行线、角平分线、中点、组，度量的都是含变量的解析式。

🧮 符号计算

求导、积分、极值/驻点/零点；解析解返回含变量的精确表达式，替代原服务端 Python。

🔗 分享链接

URL 传值标准：曲线、点、视图、计算器、保存码，一条链接直达画板。

重点功能：计算解析解并化简（带变量）

在主项目 文档 → 啊这计算器 中输入表达式，点“计算解析解并化简”： 方程与方程组返回精确解；画板函数 gj / gs / gc / gd / gz / gl 会被展开成含变量（如 a）的符号表达式，而不是代入数值的小数——与原服务端行为一致。

示例1：gj(1,0,0,0,) 求曲线1与曲线0交点的 x 坐标（支持末尾多逗号写法）。
index.html?calcxj=x^2=4 打开画板并求解 →
index.html?calcxj=2x+3y=12,%20x-y=1 打开画板并求解 →
index.html?f1=x^2&f2=1&calcxj=gj(1,0,0,0,) 带画板曲线的交点解析解 →
index.html?calcxj=gj(1,0,0,1,)^2-gj(1,0,0,0,) 交点坐标混合运算 →
