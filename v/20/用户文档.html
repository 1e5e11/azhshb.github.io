啊这函数画板 · 用户文档

本地合并版 v20 · 无需安装、无需联网、纯浏览器运行 · 官网 http://h.ssssssss.eu.org/

一、快速开始

  1. 用浏览器（推荐 Chrome / Edge）打开 index.html，或先打开 welcome.html 点“进入主项目”。
  2. 页面加载完毕后即自动以“本地用户”身份登录，全部功能已解锁，不再需要账号或服务器。
  3. 顶部输入解析式（如 x^2）、颜色、取值范围，点“创建”即可画图；拖动空白处移动坐标系，滚轮缩放。
  4. 主界面“文档”按钮、入口页与本文档之间可互相跳转；分享画板按URL 传值标准拼一条链接即可。
本项目完全离线可用：把整个文件夹拷到 U 盘或内网，双击 index.html 就能用。

二、重点：计算解析解并化简（带变量）

入口：主项目 文档 → 啊这计算器，在“输入要计算的表达式”框输入后点 “计算解析解并化简”（或“化简”）。结果可“同步结果到输入框”继续运算，或下载为文件。

2.1 三类输入

输入类型行为示例
普通表达式精确化简（分数、幂、多项式展开合并）(x+1)^2-(x-1)^2 → 4*x
方程 / 方程组返回精确解析解；一次/二次方程用符号求根公式，支持含变量系数x^2=4 → x=-2, x=2；2x+3y=12, x-y=1 → x=3, y=2
含画板函数 g*先展开成含变量的符号表达式，再求解/化简（见 2.2）gj(1,0,0,0,) → 含 a 的表达式

2.2 画板函数的符号展开（与原服务端行为一致）

画板对象之间用 g* 函数互相引用。解析解不会把变量代入成小数，而是返回含变量符号的精确表达式。 例如画板中有变量 a、点0 (a, 2)、点1 (2, 5a+3)、 曲线0 gs(x,1,0)（过这两点的函数）、曲线1 1：

gs(x,1,0,h)   →   (5*a + 1)*x/(-a + 2) + (5*a^2 + 3*a - 4)/(a - 2)
gd(0,0)       →   a
gj(1,0,0,0,)  →   两曲线交点的 x 坐标（含 a 的精确表达式）
gj(1,0,0,1,)  →   交点的 y 坐标（此例为 1）

把变量 a 的值改为任意数，表达式随之精确成立（a=-3.62 时 gj(1,0,0,0,) = -3.2913…，与画板绘制一致）。

2.3 画板函数速查

函数含义符号展开结果
gc(变量号, xy)引用变量变量名符号（如 a）
gd(点号, xy)点的 x/y 坐标（xy=0/1）坐标表达式（递归展开）
gh(曲线号)曲线的解析式含变量的解析式
gz(曲线号, 变量号, x值)曲线在某处的函数值代入后的表达式
gs(x, 点1, 点2, …[, h])过几点的函数；带 h 返回解析式两点→一次函数；多点→拉格朗日插值
gj(曲线1, 曲线2, 序号, xy)两曲线第“序号”个交点，xy=0 取 x / 1 取 y / 2 取个数关于 x 解方程的精确根（±根号/分数形式）
gl(点1, 点2)两点距离平方根表达式
go/gi/gp/gw/gg/wt/rt斜率/角度/角平分线等按当前数值计算（无符号解析式）
gj 支持工程里常见的末尾多逗号写法（如 gj(1,0,0,0,)），全角逗号/括号也会自动纠正。
符号求根覆盖一次、二次方程；更高次仅在系数全为数字时求精确根，否则自动回退为按当前变量值的数值计算。gj 的交点序号与绘制时的数值搜索顺序可能不同，多交点时建议逐一确认。

四、URL 传值标准（分享链接）

在 index.html 后附加查询参数即可一键还原画板状态。所有参数均可选、可组合。

1. 曲线（最多 9 条）

参数说明示例
f1 … f9曲线解析式（标准语法）f1=sin(x)/x
c1 … c9对应颜色（颜色名或 #rrggbb）c1=blue
r1 … r9对应取值范围，格式 下限:上限r1=-5:5

快捷写法：f=、c=、r= 等价于 f1=、c1=、r1=。

2. 点（最多 9 个）

参数说明示例
p1 … p9点坐标，格式 x,yp1=3,2
p1n … p9n点名称（可选）p1n=A

3. 视图与画板

参数含义默认
x / y坐标系原点位置（像素）300 / 400
z缩放（20 = 1:1）20
w / h显示宽 / 高（像素）1000 / 800
g绘制精度（每条曲线采样点数）100

4. 计算器与其它

参数说明
calc表达式：填入“啊这计算器”并自动打开该面板
calcxj表达式：填入并自动执行“计算解析解并化简”（支持方程、方程组、g* 画板函数）
t页面标题
azx保存码（“保存”生成的 LZString 压缩串），打开时自动恢复整个画板

5. 完整示例

index.html?f=sin(x)/x&c=blue
index.html?f1=x^2&f2=-x^2+8&c1=red&c2=green&z=30
index.html?calcxj=x^2=4
index.html?f1=x^2&f2=1&calcxj=gj(1,0,0,0,)
index.html?t=我的画板&g=200&f=(x-1)^2-(x+1)^2
解析式中的 + 直接写即可；如链接会经过吞符号的渠道，可把 + 写成 %2B。welcome.html 里有可视化的“分享链接生成器”。

五、本地房间（原联机功能）

本版本把原 Node.js 服务器（AZTXserver.js）合并进客户端，房间与聊天全部在本地完成：

  • 创建房间：生成 5 位房间号，并保存当前画板快照。
  • 加入房间：输入房间号，自动恢复该房间的画板快照。
  • 同步信息：每次改动自动更新房间快照（仅保存在本机内存）。
  • 聊天：消息与历史记录保存在本地。
与旧版不同：本地模式没有真正的多人实时同步（无服务器可中转）。若需多人协作，请用 URL 分享链接或 .azx 文件交换画板。

六、设置与跑分

  • 设置面板：主题颜色/透明度、文字颜色、背景、网格乘数、容差等。修改前建议先阅读本节（主界面设置面板右上角文字可点击直达这里）。
  • 清空设置：恢复默认主题；导出设置：把当前设置导出为文件。
  • 跑分：随机生成 10000 条算式并求值，得分 = 10000000 ÷ 耗时(ms)，越高越快。结果弹窗显示并写入日志，不会改动画板内容。

七、常见问题（FAQ）

  • Q：还连不上 120.48.70.244 / ssssssss.eu.org？
    不需要。本版本已完全离线，任何远程连接代码都已被移除或短路；官网仅为 http://h.ssssssss.eu.org/。
  • Q：解析解为什么会返回含 a 的表达式而不是小数？
    这正是本功能的设计：画板函数按符号展开，变量保持符号，得到随变量变化的精确解析式。需要数值时把 a 的具体值代入即可。
  • Q：化简结果出现 i（虚数单位）？
    说明表达式涉及复数（如 sqrt(-1)），属正常结果。
  • Q：为什么 103^34243 不显示 Infinity？
    “化简”按钮使用 BigInt 任意精度有理数计算，会展开成完整的精确整数，而不是用双精度浮点求近似值。
  • Q：gj 报“曲线不存在/未找到结果”？
    检查引用的曲线/点/圆编号是否存在于画板，以及交点是否真的存在（如两平行线无交点）。
  • Q：如何恢复上次画的内容？
    ① 打开保存的 .azx 文件；② 粘贴保存码；③ 若创建过本地房间，重新加入该房间号即可恢复快照。
  • Q：加载速度为什么变快了？
    脚本改为 defer 并行下载、按序执行，浏览器原生缓存替代旧的 localStorage+eval 缓存，启动即初始化。

八、附录：实现原理（简要）

  • Encrypted.JS / s.js / dc.JS / la.js：画板主体——对象数据模型（函数/点/变量/组列表）、Canvas 绘制、几何构造与微积分。
  • algebrite.bundle-for-browser.js / math.js：符号计算库（求导、积分、roots、有理化等）。
  • nerdamer.core.js + nerdamer.calculus.js / nerdamer.algebra.js / nerdamer.solve.js（后三个为本版本新增的 nerdamer 扩展）：分式通分约简（同 sympy.cancel，默认分母不为 0）、因式分解、方程组求解。
  • az_simplify.js（新增）：精确有理数化简引擎——Frac 分数类基于 BigInt，递归下降解析器 + AST 化简，取自 simplifier (1).html。化简按钮对大整数幂（如 103^34243）执行任意精度精确展开，不再溢出为 Infinity。
  • az_server_jx.js（新增）：原封移植 serverdesktop\AZTXserver2.js 的 jsjxj 解析解引擎（hqjxj/cljxs/azgetjd_w/jiaodian_*_w 等），g* 调用展开为含变量符号的精确表达式；仅其化简环节 senpoly 由原 pyhuajian2(Python) 替换为本地化简器，并补充了分式约简（nerdamer gcd，等价 sympy.cancel）。
  • az_local.js（新增）：①本地环回总线，替代 AZTXserver.js（登录/房间/聊天/同步/心跳全部本地）；②方程/方程组精确求解（一次/二次符号求根 + Frac 高斯消元）、解析解回退引擎、普通表达式 AZSimplify / nerdamer(约分) / Algebrite 多级兜底。
  • az_url.js（新增）：URL 传值标准解析器（安全，无 eval），含 calc/calcxj 计算器直达。
  • welcome.html：入口/示例页；用户文档.html：即本文档，与主界面“文档”按钮互通。
